# 📝 OOP Assignments & Lab Modules

> Practice labs and assignments covering real-world applications of Java Object-Oriented Programming.

---

## 📋 Included Assignments

- `BankAccount.java`: Bank account operations with minimum balance enforcement.
- `MatrixAddition.java`: 2D Matrix input, display, and addition.
- `LibraryBookManagement.java`: Book, author, and pricing management system.
- `UniversityCourseRegistration.java`: Student course enrolment and date tracking.
- `StudentGradeCalc.java`: Grade calculation and static university name modifications.
- `ComputerLaptopInheritanceLab.java`: System specifications inheritance hierarchy.
- `PublicationInheritanceLab.java`: Book & audio tape publication management.
- `PersonEmployeeHierarchyLab.java`: Person, Employee, Faculty, and Staff hierarchy.
- `StudentGradingLab.java`: Student object counters and static uni methods.
- `Exam.java`: Exam practice with static and final variables.

---

## 🚀 How to Run

```bash
cd OOP_Assignments
javac <FileName>.java
java <ClassName>
```
