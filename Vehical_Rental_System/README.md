# 🏎️ Vehicle Rental System

> Polymorphic vehicle rental platform implementation featuring abstract base classes, specialization (Car, Bike, SUV), and daily rate calculations.

---

## 🚘 Vehicle Types

- `Car`: Standard passenger vehicle rental calculations.
- `Bike`: Two-wheeler rental options.
- `SUV`: Heavy duty spacious vehicle rental.

---

## 🚀 How to Run

```bash
cd Vehical_Rental_System
javac *.java
java Main
```
