# 🎨 JavaFX GUI Applications & Demos

> A dedicated project suite showcasing JavaFX desktop GUI components, event handling, scene graph layouts, and FXML integration.

---

## 💻 Included Applications

### 1. `demo` (Maven JavaFX Project)
A structured JavaFX project with modular build configuration (`module-info.java`), FXML layouts, and custom UI image assets.
- **Entry Point:** `HelloApplication.java`
- **Controller:** `HelloController.java`
- **View:** `hello-view.fxml`

### 2. `ludo` (Ludo / GUI Component Demo)
Basic JavaFX controls setup demonstrating layout management (`VBox`), interactive controls (`Button`, `TextField`, `Label`), and event handling.
- **File:** `ludo/src/javafx_1.java`

---

## 🛠️ Tech Stack

- **Framework:** JavaFX 17+
- **Build Tool:** Maven
- **UI Components:** FXML, Controls, Layout Containers (VBox, Scenes, Stages)

---

## 🚀 How to Run

### Run Maven Demo App:
```bash
cd javafx/demo
./mvnw javafx:run
```
