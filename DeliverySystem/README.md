# 🚚 Delivery & Restaurant Management System

> An Object-Oriented Java project simulating restaurant menus, customer ordering workflows, and delivery price calculations.

---

## 💡 Key Concepts Covered

- **Class Aggregation & Composition**: Restaurants containing `Menuitem`s and `Order`s tracking items.
- **Encapsulation**: Private fields with validation getters and setters.
- **Overloaded Constructors & Copy Constructors**: Deep copying menu items and order setup.

---

## 📁 Class Overview

- `Resturant.java`: Manages restaurant details, rating, and menu catalog.
- `Menuitem.java`: Represents individual food items with pricing and category.
- `Order.java`: Handles customer orders and total cost calculations.
- `Main.java`: Test driver demonstrating order placing and invoice generation.

---

## 🚀 How to Run

```bash
cd DeliverySystem
javac *.java
java Main
```
