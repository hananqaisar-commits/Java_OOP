# 🚗 GarageX — Vehicle Showroom System

> A polished Java OOP application implementing abstract classes, inheritance, runtime polymorphism, and composition with vehicle engine management.

---

## 🚘 Architecture & Concepts

- **Abstract Base Class**: `Vehicle` base class storing name, company, and composing an `Engine`.
- **Inheritance & Polymorphism**: `Car` and `Bike` concrete classes extending `Vehicle`.
- **Composition**: `Engine` class with CC capacity and fuel type tracking.
- **RTTI & Downcasting**: Demonstrating `instanceof` checks to segregate cars vs bikes in showroom inventory loops.

---

## 🚀 How to Run

```bash
cd GarageX_VehicleShowroom
javac GarageX.java
java Main
```
