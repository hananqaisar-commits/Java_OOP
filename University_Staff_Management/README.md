# 🏛️ University Staff Management System

> An OOP inheritance hierarchy modeling university employees (Faculty & Admin Staff) with polymorphic salary calculations and hiring dates.

---

## 👥 Inheritance Hierarchy

```
Person (Base Class)
  └── Employee
        ├── Faculty
        └── AdminStaff (Staff)
```

---

## 🚀 How to Run

```bash
cd University_Staff_Management
javac *.java
java Main
```
