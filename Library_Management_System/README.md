# 📚 Library Management System

> A Library Management System in Java utilizing abstract `LibraryItem`s, `Book`s, and `Magazine`s to handle library cataloging and checkouts.

---

## 🛠️ Architecture

- `LibraryItem`: Abstract base item with title, item ID, and availability state.
- `Book`: Specialized library item with author and page count.
- `Magazine`: Specialized library item with issue number and frequency.
- `Library1`: Catalog manager for adding and borrowing items.

---

## 🚀 How to Run

```bash
cd Library_Management_System
javac *.java
java Main
```
