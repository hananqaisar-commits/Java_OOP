# ☕ BasicOOP — Core OOP Foundations & Exercises

> A comprehensive collection of fundamental Java OOP concepts, data structures, constructors, and inheritance/polymorphism exercises.

---

## 📁 Sub-directories & Categories

- **`File_Handling/`**: File IO operations using `Files.writeString` and custom text parsing (`TextFileIO.java`).
- **`Inheritance/`**: Inheritance concepts, method overriding, and `super` vs `this` usages (`ThisVsSuperDemo.java`).
- **`Polymorphism/`**: Method overloading vs overriding (`OverloadingAndOverridingDemo.java`) and abstraction practice (`AbstractionPractice.java`).
- **`Product_Sorting/`**: Sorting objects using `Comparable` and custom `Comparator` implementations.

---

## 🚀 How to Run Any Demo

```bash
cd BasicOOP
javac <FileName>.java
java <ClassName>
```
